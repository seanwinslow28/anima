PEGBAR
the production office.

The interface is living animation paperwork — the X-sheet, the route sheet, the light table, the stamp. Ninety years of studio production discipline is a UI system that already works; anima fills in the forms as the run happens. The reversal that carries it: the critic writes in col-erase blue — the pencil the camera can't photograph — so a proposal is structurally unshippable. Only the human's red stamp is final.

How it serves the soul

The critic proposes, never decides — made physical. Em's verdicts, reasoning, and fixes render in non-photo blue, the animation industry's own ink for under-drawing that the rostrum camera never sees. Her note literally cannot ship. The only red on any surface is the human's stamp and grease pencil. Approval is a stamp with a thunk; a retake is a stamp with a note riding the camera report.

The pipeline is the portfolio piece — paperwork is receipts. Struck shots stay on the route sheet, crossed out; every stamp carries initials and a date; the cost ledger is an adding-machine tape. The office never erases, so the museum's evidence trail falls out of the interface for free.

Read like a studio, not a terminal — literally the studio's own documents. The X-sheet grid (a heavy rule every 8th row, ○ keys, | holds) is the reel; "footage" and "cuts" replace list rows. And iteration is cheap reads as what it is: another sheet of paper on the pegs.
