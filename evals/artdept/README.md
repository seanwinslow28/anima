# evals/artdept — the Art Department bundle eval

## What's here

`fixtures/grandmaster-mini/` is a committed, minimal, `mode: fixture`
Art Department bundle, shaped by the real 2026-07-14 GRANDMASTER
character-design sprint (kid + grandma, both `primal-sketch-grit`). It exists
so `pipeline.artdept.validate.validate_artdept_dir` has a known-good structural
target to check itself against between live sessions, and so a future
orchestrator/synthesize skill build has a worked shape to emit toward.

`fixtures/grandmaster-mini/refs/*.png` are 1×1 placeholder PNGs — clearly
named, never real anchors. The ratified GRANDMASTER anchors are gitignored
run artifacts (`runs/2026-07-14-grandmaster-kid-design/`); nothing about their
pixels is asserted here, only that the bundle's paths resolve.

`fixtures/grandmaster-mini/cy_readiness_report.md` was generated by calling
the real `readiness_report()` against the worktree's actual `manifest.yaml` —
kid and grandma are genuinely unregistered there, so the report honestly
reads NOT Cy-ready for both. It is not hand-written prose.

## What the fixture is — and isn't

The fixture is a **structural reference**, never a quality oracle. Passing
`validate_artdept_dir()` proves a bundle has the right files, the right
cast-list shape, and resolvable anchor refs. It says nothing about whether
the design is *good* — whether the register fits, whether identity survives
a fork, whether the prompt pack actually reproduces the locked look. That
judgment is Sean's live eye, scored against
`.claude/skills/art-department/references/good-look-test-rubric.md` (built
alongside the orchestrator skill).

## Live-validation protocol — Checkpoint 3

Checkpoint 3 is a **Sean-run live Art Department session** on a real piece
(GRANDMASTER's host-dad — the only one of the three characters still
undesigned — or the next greenlit piece). Artie runs the room.

1. Sean declares a session credit budget up front, before any generation
   fires.
2. The session runs the room end to end: interrogate → look-test → lock →
   synthesize, producing a real (`mode: interactive`) bundle dir.
3. The session ends with **both** of the following true:
   - `python -m pipeline.artdept validate <bundle>` exits 0 (structure holds
     — no missing files, no unresolved anchors, no cast/handoff mismatch).
   - Sean scores the session against
     `good-look-test-rubric.md`, where **criteria 1–3 block together**
     (apples-to-apples contested-fork comparisons, identity survives the
     fork, every lock is a named specific with a recorded why) — a session
     that passes the CLI but fails the block is not a pass.

Until that session runs, Checkpoint 3 status is **pending**. This fixture and
its two `test_artdept_fixture.py` cases are the $0 structural proof that can
run indefinitely between costed live sessions; they are not a substitute for
Checkpoint 3 itself.
